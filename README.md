# 🛒 Zepto SQL Data Analysis Project

## 📌 Project Overview

This project focuses on analyzing Zepto's product inventory dataset using SQL. The objective is to explore the dataset, clean the data, and extract meaningful business insights related to product pricing, discounts, stock availability, and category-wise performance.

## 🎯 Objectives

- Perform data exploration and validation
- Identify missing and inconsistent values
- Analyze product pricing and discounts
- Examine stock availability
- Generate category-level insights
- Practice real-world SQL data analysis techniques

## 📂 Dataset Information

The dataset contains information about products available on Zepto, including:

- Product Name
- Category
- MRP (Maximum Retail Price)
- Discount Percentage
- Discounted Selling Price
- Available Quantity
- Weight in Grams
- Stock Status

Dataset File: `zepto_v2.csv`
